## Repository Directory Structure

This repository contains the files required to reproduce the experiments and analyses associated with the ReactiTwin artefact. The main directories are organised according to the different experimental activities as follows:

- **`Relation_Networks_Model`** contains the files required to reproduce the training of the Relation Network model used in the experiments.

- **`ReactiTwin`** contains the files required to reproduce the ReactiTwin artefact and its experimental execution.

- **`TTD_TTR_measurement_series`** contains the files associated with the experimental measurement campaigns for **Time-To-Detection (TTD)** and **Time-to-Remediation (TTR)**.

- **`Availability_measurement`** contains the files associated with the availability measurements of the Digital Twin prototype's web-based human–machine interface (HMI).
